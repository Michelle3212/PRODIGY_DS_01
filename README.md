## Task-01: Data Visualization

This project focuses on visualizing global population data using the World Population dataset.

### 📊 Dataset:
- World Population Dataset (world_country_stats)

### 🔧 Tools Used:
- Python
- Pandas
- Matplotlib
- Seaborn

### 📈 Work Done:
- Created bar charts to visualize categorical distribution of countries by region
- Used histograms to analyze continuous variables:
  - Median Age
  - Fertility Rate
  - Land Area
- Applied log transformation on land area to handle skewness

### 📌 Key Insights:
- Population and land area distributions are highly skewed
- Log transformation helps normalize large-scale differences
- Regional comparisons show clear variations in demographic patterns

### 📷 Output:
- Bar charts for region-wise distribution
- Histograms for continuous variables
- Log-transformed visualization of land area
